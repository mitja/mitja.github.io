{{- /* youtubeLink — a YouTube video as a preview image that links to YouTube. Privacy-friendly: the page loads nothing from YouTube or Google; only a click opens YouTube in a new tab (privacy statement, section "Websites"). Hugo's own `youtube` shortcode embeds an iframe and Blowfish's `youtubeLite` loads the thumbnail from i.ytimg.com, so neither fits. Usage: {{< youtubeLink id="z8xi44O3hvY" label="Ollama on Windows" >}} The preview image is fetched at BUILD time (locally and in CI) with resources.GetRemote from i.ytimg.com (maxresdefault, else hqdefault), cropped to 16:9, converted to WebP and served from this site. Hugo caches it (resources/_gen, getresource cache). To use your own image instead, put youtube-.jpg|png|webp into the page bundle. */ -}} {{- $id := .Get "id" -}} {{- if not $id }}{{ errorf "youtubeLink: missing id in %s" .Page.File.Path }}{{ end -}} {{- $label := .Get "label" | default "Video" -}} {{- $de := eq .Page.Language.Lang "de" -}} {{- $url := printf "https://www.youtube.com/watch?v=%s" $id -}} {{- $src := .Page.Resources.GetMatch (printf "youtube-%s.*" $id) -}} {{- if not $src -}} {{- range slice "maxresdefault" "hqdefault" -}} {{- if not $src -}} {{- with try (resources.GetRemote (printf "https://i.ytimg.com/vi/%s/%s.jpg" $id .)) -}} {{- with .Value -}}{{- $src = . -}}{{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $src }}{{ warnf "youtubeLink: no preview image for %s (%s); showing a text link" $id $.Page.File.Path }}{{ end -}} {{- $img := "" -}} {{- with $src -}} {{- $w := cond (ge .Width 1280) 1280 (cond (ge .Width 960) 960 640) -}} {{- $img = .Fill (printf "%dx%d Center webp q80" $w (div (mul $w 9) 16)) -}} {{- end -}}
